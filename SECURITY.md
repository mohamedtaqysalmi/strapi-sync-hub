# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's private reporting instead:
go to the [Security tab](https://github.com/mohamedtaqysalmi/strapi-sync-hub/security) and choose
"Report a vulnerability".

This is a solo-maintained project in early development. I will try to acknowledge a report within a
few days, but I cannot promise a fixed response time.

## Supported versions

Nothing has been released yet. Once there are releases, only the latest one will get fixes.
