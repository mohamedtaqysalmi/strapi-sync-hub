strapi-sync-hub

A small FastAPI service that takes Strapi entry webhooks, maps fields from YAML, and upserts into Meilisearch (or a JSON webhook) with retries, a dead-letter log, dry-run, and full reindex.

Map a content type Open the repo

Architecture

Strapi fires entry events. The hub verifies a shared secret, maps the model, then writes to the target. Failed writes retry with backoff; exhausted attempts land in a JSONL dead-letter file. 

Strapi webhook
    │  X-Sync-Secret
    ▼
verify → map YAML → upsert / delete
    │                    │
    │              retry × N
    │                    │
    └────────────► dead-letter.jsonl
                         │
              Meilisearch / JSON webhook
  • Idempotent upserts compare _source_updated_at and skip stale events.
  • Drafts (publishedAt: null) never become searchable.
  • Contract fixtures are hand-written from Strapi docs, not recorded from a live CMS.

Config examples

        
Environment variables validated at startup. Bad config stops the process.

        

          

            
Meilisearch target

            
STRAPI_SYNC_SECRET=…at-least-16-chars…
STRAPI_SYNC_TARGET=meilisearch
MEILISEARCH_URL=http://localhost:7700
MEILISEARCH_API_KEY=
STRAPI_SYNC_MAPPING=mapping.yaml
STRAPI_SYNC_MAX_RETRIES=3
STRAPI_SYNC_DEAD_LETTER_PATH=dead-letter.jsonl

            
          

          

            
Full reindex

            
STRAPI_URL=http://localhost:1337
STRAPI_API_TOKEN=…
strapi-sync-hub reindex
strapi-sync-hub reindex --dry-run --content-type article
